# 💰 記帳本（手機記帳工具）

一個單一檔案、免伺服器的記帳網頁 App，資料儲存在手機/瀏覽器本機（localStorage）。

## 功能
- 支出 / 收入兩種記錄
- 分類：食物、交通、購物、居家、娛樂、醫療、教育、其他（收入：薪資、獎金、投資、其他）
- 可選擇消費日期（預設今天）
- 備註欄位
- **本週 / 本月** 切換，顯示總收入、總支出與結餘
- 明細依日期分組，可刪除單筆記錄

## 怎麼用（手機）
1. 把 `index.html` 放到手機可開啟的位置，或用 GitHub Pages 等服務開啟網址。
2. 用手機瀏覽器打開後，可點「分享 → 加入主畫面」，就能像 App 一樣使用。
3. 資料只存在這支手機的這個瀏覽器，清除瀏覽器資料會一併清掉記錄。

## 怎麼用（電腦預覽）
直接用瀏覽器打開 `index.html` 即可。

> 注意：資料儲存在瀏覽器本機，換裝置或換瀏覽器不會同步。若需跨裝置同步，未來可再加雲端儲存。
